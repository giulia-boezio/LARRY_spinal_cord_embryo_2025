# Hierarchical lineage architecture of human and avian spinal cord revealed by single-cell genomic barcoding
Scripts for analysis in Boezio et al (2025)

This repository contains the code, data references, and notebooks used in the analyses for the paper:

Hierarchical lineage architecture of human and avian spinal cord revealed by single-cell genomic barcoding

Giulia L. M. Boezio, Jasper R. L. Depotter, Arthur Radley, Thomas J. R. Frith, Dimitris Volteras, Ashley Libby, Stephanie Strohbuecker, Ana C. Cunha, Michael Howell, James Briscoe

https://www.biorxiv.org/content/10.1101/2025.10.24.684328v1.full


## Overview

The repository includes:
- Python notebooks, Python scripts, and R Markdown files for data processing and figure generation
- Links to data hosted on GEO (GSE312424)
- A reproducible environment for Python code

The repository does not include:
- Raw FASTQ files and preprocessed Seurat/h5ad objects (available to download from GSE312424)
- LARRY clone output (generated by the nf-LARRY pipeline: https://github.com/FrancisCrickInstitute/LARRY; available to download from GSE312424)

## Jupyter notebooks / Python scripts: execution order, inputs, and outputs

Notebooks are named with a suffix reflecting the dataset they apply to. Steps follow the same order for all datasets.

---

1. `Preprocessing_chicken_data_*.ipynb` OR `Preprocessing_human_data.ipynb`  
   Preprocessing of single-cell data: QC, clean-up, preliminary clustering, exclusion of contaminating cell types.  
   INPUT: CellRanger output (`filtered_feature_bc_matrix`)  
   OUTPUT: `preprocessing_larry_*.h5ad`

2. `cesfw_chicken_data*.py` OR `cesfw_human_data.py`  
   Extracts cESFW features from the preprocessed data.  
   INPUT: `preprocessing_larry_*.h5ad`  
   OUTPUT: `ESSs.npy`, `Used_Features.npy`, `EPs.npy`

3. `CESFW_feature_selection_chicken_*.ipynb` OR `CESFW_feature_selection_human_data.ipynb`  
   Clusters and selects cESFW features.  
   INPUT: `ESSs.npy`, `Used_Features.npy`, `EPs.npy`, `preprocessing_larry_*.h5ad`  
   OUTPUT: `selected_cesfw_features_*_data.npy`

4. `Integration_chicken_*.ipynb` OR `Integration_human_data.ipynb`  
   Creates the final integrated h5ad files using scVI and cESFW features; adds LARRY clone assignments and cell-type annotation.  
   INPUT: `preprocessing_larry_*.h5ad`, `selected_cesfw_features_*_data.npy`, `*_LARRY_*_clone_output.csv` (from nf-LARRY, deposited on GEO)  
   OUTPUT: `larry_*.csv` (metadata), `preprocessing_larry_*_clusters.h5ad` (final annotated object, deposited on GEO), optional CSV for Seurat conversion

5. `permutation_analysis_*.ipynb` (uses `permutation.py`)  
   Permutation-based lineage correlation analysis.  
   INPUT: `larry_*.csv`, `permutation.py`  
   OUTPUT: lineage correlation matrix plots

6. `wave_analysis_*.ipynb` (uses `permutation.py`)  
   Temporal wave analysis of clone sharing across collection timepoints.  
   INPUT: `larry_*.csv`, `permutation.py`  
   OUTPUT: lineage correlation matrix plots

7. `scLiTr-analyses_*.ipynb`  
   scLiTr (single-cell lineage trajectory) analyses. For the injHH12-collHH28-31-35 notebook, toggle `mode="all"` to analyse all timepoints combined or `mode="per_timepoint"` with `target_experiment` for a single timepoint.  
   INPUT: `preprocessing_larry_*_clusters.h5ad`, `larry_*.csv`  
   OUTPUT: scLiTr clone embeddings, fate commitment plots, SHAP feature importance

## R Markdowns

R Markdowns require R with Seurat v4 or v5. Input `.rds` files are deposited on GEO (GSE312424).

Run the two conversion notebooks first to generate Seurat objects from the Python h5ad outputs, then run the figure notebooks.

### Conversion (run first)

- `convert_anndata_seurat_chicken.Rmd` — converts chicken h5ad files (from the Integration notebooks) to Seurat RDS objects
- `convert_anndata_seurat_human.Rmd` — converts human h5ad files to Seurat RDS objects

### Figure notebooks

- `Figure1-S1-S2_new.Rmd` — Fig 1, S1, S2: clone QC, LARRY detection rates, marker validation (AUC/Gini), UMAPs, DV clone size analyses (scRNA-seq and immunofluorescence), clonal confinement. Requires `LARRY_detection_summary_per_sample_HH16HH31.csv` produced by `analyses_injHH16-collHH31.Rmd`, and `counts_clones_HH28.xlsx`.
- `Figure3-S6_new.Rmd` — Fig 3, S6: V0/V2 subtype analysis, neuronal wave characterisation and sharing, OPC clonal analysis, Renshaw network, temporal transcription factor dotplots
- `Figure4-S7.Rmd` — Fig 4, S7: dI4/dI5 identity, clonal co-occurrence, proportional dynamics across timepoints, DEGs, mouse comparison
- `Figure5-S8.Rmd` — Fig 5, S8: H9-RFP human stem-cell in vitro clonal analysis; dI4/(dI4+dI5) ratio histograms and KDE plots for clones labelled at D14 (145 clones) and D20 (117 clones), analysed at D28. Requires `H9_D14-D28_clonal_counts_fixed.csv` and `H9_D20-D28_clonal_counts_new.csv`.
- `Figure6-S9-S10.Rmd` — Fig 6, S9, S10: human CS16/CS17 LARRY dataset; dI4/dI5 clonal classification, DEGs, Spearman correlation with Rayon in vivo reference, binomial mixture modelling with bootstrapping

### Additional analyses

- `analyses_injHH16-collHH31.Rmd` — clone QC for the injHH16-collHH31 dataset, which was generate in Python; produces `LARRY_detection_summary_per_sample_HH16HH31.csv`, which is required as input by `Figure1-S1-S2_new.Rmd`
- `cluster_annotation_injHH7-collHH18.Rmd` — cluster annotation for the injHH7-collHH18 dataset
